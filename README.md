### 🚀 Featured Project

<div align="center">
  <h3>🔥 VectorForge — High-Performance Vector Search Engine & Local RAG</h3>
</div>

**VectorForge** is an end-to-end vector search engine built from scratch in C++ that enables lightning-fast high-dimensional vector index lookup and local Retrieval-Augmented Generation (RAG) powered by Ollama.

* **Indexing Algorithms:** Implemented **HNSW** (Hierarchical Navigable Small World graphs), **KD-Tree**, and Exact **BruteForce** nearest-neighbor search.
* **Local RAG Integration:** Connects C++ similarity search directly to local LLMs via Ollama for zero-cloud latency context retrieval.
* **Systems Focus:** Memory-efficient data structures and low-overhead vector computations tuned for speed.

**Tech Stack:** `C++` • `Algorithms & Data Structures` • `Vector Indexing` • `Ollama (Local LLM)` • `RAG`
